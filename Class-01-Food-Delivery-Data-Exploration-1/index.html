Why is NumPy faster? Two tea rooms

🎤
Room 1: tea, sugar, milk and cups lie around the house. Room 2: all on one shelf. Where is tea ready first?
NumPy is Room 2.
  • A list is Room 1. It keeps addresses. The values lie around the house.
  • An array is Room 2. The values sit side by side, all of one type: one shelf.
In its block of memory, does a NumPy array store the address of each element or the value itself?
The actual value. No jumping around to find each number. That is the shelf in Room 2.
The values themselves, in a row.

Why is NumPy faster? It works closer to the machine

  • Higher levels are easier for people. Lower levels are faster for the machine.
The same addition at four levels. The machine only understands the last one.
  • One billion loop steps: Rust takes 0.50 seconds. Python takes 74.42 seconds.
  • Watch them race: 1 billion loop iterations, by Benjamin Dicken.
✋
We use NumPy from Python. Where does its loop over the numbers really run?
In Python, one element at a time
In compiled C code
In assembly that we write ourselves
  • NumPy itself is written mostly in C.
  • You write one line of Python. The loop runs in compiled C.
You write Python. NumPy runs the heavy loop in C.
NumPy: easy like Python, fast like C.

See it: one million numbers

import time
import numpy as np

n = 1_000_000
numbers_list = list(range(n))
numbers_array = np.arange(n)

start = time.time()
doubled_list = [x * 2 for x in numbers_list]
list_seconds = time.time() - start

start = time.time()
doubled_array = numbers_array * 2
array_seconds = time.time() - start

print(f"List:  {list_seconds:.4f} seconds")

An array holds one type only

  • Mix types, and NumPy converts everything to the "highest" one.
Each type can become the one to its right. String is the highest.
You writeNumPy stores
np.array([1, 2, 3.5])[1. 2. 3.5] all floats
np.array([1, "Akash", 3.5])['1' 'Akash' '3.5'] all strings
np.array([True, 6])[1 6] True became 1
What does np.array([10, 2.5, "7"]) store?
Three strings. One string in the list is enough: String is the highest type, so 10 and 2.5 become text too.
One string turns the whole array into text.
Four integers and one string. How does NumPy choose the one type?
np.array([1, "two", 3, 4, 5])
The type that can hold every value. "two" cannot become a number, but 1, 3, 4 and 5 can become text: ['1' 'two' '3' '4' '5']. Not the first, not the majority.
A value can move right and lose nothing. Text cannot move left.

Why 32, when "3.5" has only 3 characters?

✋
np.array([1, "Akash", 3.5]) has dtype <U32. The longest text is "Akash": 5 characters. Why 32?
It adds up all the characters in the array
It keeps room for the longest float there could be
Every text array gets 32
  • NumPy does not measure 3.5. It asks: how long can any float be, written as text?
  • A float can be long: -1.7976931348623157e+308 is 24 characters. NumPy keeps 32 to be safe.
You writedtypeWhy

np.array([1, "Akash"])<U21room for any integer: up to 20 digits and a sign
np.array([3.5, "Akash"])<U32room for any float
The number after U is the room kept for each element, not the length of your data.

Why transpose? One row per restaurant

🎤
We stack votes and costs into one array. Where is the data of restaurant 0?
One restaurant, one row: its votes and its cost sit together.
  • After .T: one row per restaurant. Related data stays together.
  • Data tables are kept this way: one row per record, one column per attribute.
  • Where else is transpose used?
  • Maths: it makes two matrices fit for multiplication.
  • Images: a photo is a grid of numbers. Transpose flips it along the diagonal.
  • AI: the attention formula inside every LLM has a transpose in it.

One column: what shape comes back?

✋
3 rows, 2 columns. Take every row, column 0. What prints?
arr = np.array([[1, 2],
                [3, 4],
                [5, 6]])

print(arr[:, 0])
[1 2]
[1 3 5]
[[1] [3] [5]]
[1 3 5]
  • Column 0 of every row: 1, 3 and 5.
  • Count the brackets: one [. So it is a 1D array.
✋
One bracket, so one number in the shape. Which one?
print(arr[:, 0].shape)
(3, 1)
(1, 3)
(3,)
(3,)
  • Three values in one row: (3,).
  • You asked for column number 0. NumPy returns its values only. The column direction is gone.
✋
Now write a slice, 0:1, where the number 0 was. What changes?
print(arr[:, 0:1])
print(arr[:, 0:1].shape)
Nothing: the same output
Two brackets, shape (3, 1)
An error
[[1] [3] [5]] (3, 1)
  • Count again: two brackets, [[. A 2D array with 3 rows and 1 column.
  • A slice keeps the direction, even when it holds only one column.
