Last class: why NumPy is fast

Why is votes * 2 faster than a Python loop over a list?
Side by side, one type, compiled C. A list keeps addresses and its values are scattered: Room 1. An array keeps the values on one shelf: Room 2. And NumPy runs the loop in C.
The values themselves, in a row.

Last class: one type only

What does np.array([7, 2.5, True]) store?
Three floats. An array holds one type. Float can hold all three values, so 7 becomes 7.0 and True becomes 1.0. And False? It becomes 0: np.array([7, 2.5, False]) stores [7. 2.5 0. ], and np.array([True, False, 6]) stores [1 0 6]. There is no string here, so nothing becomes text.
True is 1. False is 0.
Each type can become the one to its right.
  • Today we start from that one type. It has a name: dtype.

dtype: the data type of an array

  • dtype = data type: the one type that every element has.
a = np.array([1, "Akash", 3.5])
print(a)
print(a.dtype)
['1' 'Akash' '3.5'] <U32
  • One string in the list, so everything became text.
  • But what is <U32?
Read <U32 as: text, up to 32 characters each.
dtypeWhat the array holds
int64whole numbers, 64 bits each
float64decimal numbers, 64 bits each
boolTrue or False
<U5text, up to 5 characters each
What is the dtype of np.array(["abc", "de"])?
<U3. The longest string, "abc", has 3 characters. NumPy keeps room for the longest one, not the total.

Why 32, when "3.5" has only 3 characters?

✋
np.array([1, "Akash", 3.5]) has dtype <U32. The longest text is "Akash": 5 characters. Why 32?
It adds up all the characters in the array
It keeps room for the longest float there could be
Every text array gets 32
  • NumPy does not measure 3.5. It asks: how long can any float be, written as text?
  • A float can be long: -1.7976931348623157e+308 is 24 characters. NumPy keeps 32 to be safe.
You writeIts dtype, and why
np.array(["Akash", "Ria"])<U5 only text: the longest string, 5
np.array([1, "Akash"])<U21 room for any integer: up to 20 digits and a sign
np.array([3.5, "Akash"])<U32 room for any float
np.array(["Ria", True])<U5 not 4: room for any Boolean, and "False" has 5 characters
The number after U is the room kept for each element, not the length of your data.

(3, 4). Rows first: 3 inner lists, so 3 rows. Each has 4 numbers, so 4 columns. Size is 3 × 4 = 12.

               [3, 4],

               [9, 10],
               [11, 12]]])
(2, 3, 2). Count what each pair of brackets holds, from the outside in. The outer bracket holds 2 blocks. Each block holds 3 rows. Each row holds 2 numbers. Size is 2 × 3 × 2 = 12, and ndim is 3.
Count what each pair of brackets holds, from the outside in.
The second row is shorter. What does NumPy do?
np.array([[1, 2, 3],
          [4, 5]])
A ValueError. A 2D array is a full rectangle: every row needs the same number of columns. Here the rows hold 3 and 2, so there is no shape to give. You can force it with dtype=object, but then each row is a plain Python list stored inside the array: the shape is (2,), and * 2 repeats the lists. No fast maths.
Every row must have the same number of columns.

Transpose: rows become columns

✋
m has 2 rows and 3 columns. What is the shape of m.T?
m = np.array([[1, 2, 3],
              [4, 5, 6]])

print(m.shape)
print(m.T)
print(m.T.shape)
(2, 3)
(3, 2)
(6,)
(2, 3) [[1 4] [2 5] [3 6]] (3, 2)
  • .T is transpose: every row becomes a column.
  • No value changes. Only the layout.
  • Excel has it too: Paste Special, Transpose.
The first row becomes the first column. The second row becomes the second column.
Transpose swaps rows and columns.

Why transpose? One row per restaurant

🎤
We stack votes and costs into one array. Where is the data of restaurant 0?
One restaurant, one row: its votes and its cost sit together.
  • After .T: one row per restaurant. Related data stays together.
  • Data tables are kept this way: one row per record, one column per attribute.
  • Where else is transpose used?
  • Maths: it makes two matrices fit for multiplication.
  • Images: a photo is a grid of numbers. Transpose flips it along the diagonal.
  • AI: the attention formula inside every LLM has a transpose in it.

Recap

Two minutes. Three points you would tell a friend who missed today.
